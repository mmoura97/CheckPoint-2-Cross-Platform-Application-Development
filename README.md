# CheckPoint 2 - Cross-Platform Application Development

Aplicativo desenvolvido em **React Native** (com **Expo**) para a disciplina de *Cross-Platform Application Development*, com o objetivo de construir uma lista de compras interativa utilizando gerenciamento de estado e listas virtualizadas.

## 📱 Sobre o Projeto
O aplicativo permite que o usuário adicione novos itens a uma lista de compras de forma dinâmica e fluida. Ele foi estruturado seguindo os padrões recomendados de componentização e estilização com Flexbox.

## 🛠️ Tecnologias Utilizadas
* **React Native**
* **Expo**
* **JavaScript**
* **Hooks do React (`useState`)**

## 📋 Requisitos Atendidos
- [x] Título do aplicativo exibido no topo.
- [x] Campo de texto (`TextInput`) para digitação de um novo item.
- [x] Botão "Adicionar" que insere o item utilizando `useState` (utilizando o *spread operator* `[...]` para imutabilidade, sem o uso de `.push()`).
- [x] Exibição eficiente dos dados utilizando o componente `FlatList`.
